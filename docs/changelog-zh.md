# 更新日志（简体中文版）

本分支跟上游走：上游发一版，这里就把对应 tag 合进来，再把新出现的界面文字翻成中文，另外几个自己的功能一直在。下面从 **1.6.6（V166U，上一版公开发布）** 之后记起。

上游每一版的完整英文条目在 [docs/changelog.md](changelog.md)，这里只挑用户看得见的部分。

---

## 1.9.4（V194A）

上游 1.9.4（含 1.9.3，共 207 个提交），换到 1.9.4 版本线。刷机标记 `V194A` 与 `V192B` 不同，已刷 `V192B` 的机器可以直接 TF 卡刷，也会收到网络更新提示。

**新增**

- **锁屏「一览」布局**：锁屏页新增「布局」行，可选「默认」或「一览」——时间日期在顶部，歌曲带方形封面、专辑、时间和队列位置，底部是滑动解锁的旋钮。背景可选「封面主色」「纯色」「模糊封面」；「经典滑块」给旋钮灰底和划过文字的高光；「转轮解锁」让转轮推动旋钮（前转三格解锁，不到就退回），开启后锁屏亮着时转轮不再调音量。没有播放时显示锁屏图片或大时钟，长按时钟在歌曲与图片之间切换。
- **锁屏「返回键解锁」开关**：关掉后返回键在锁屏上不起作用，只能滑动解锁。默认开。
- **显示采样率**：外观里新增「显示采样率」，状态栏显示 Q2 正在输出的采样率（`44.1k`、`96k`、`192k`、`DSD64`），USB DAC 与耳机口一致；蓝牙下不显示。默认关。
- **快捷入口选择页**：「快捷入口」不再是轮换，点开是一个列表：收藏、随机播放、已评价专辑、播放列表、表演者、专辑、游戏、播客、有声读物、无，再加上卡上的应用与游戏。
- **年代分「年代 / 年份」两页**：年份按年列出有年代的专辑（新的在前），点进某一年可播放全部或随机播放。
- **Rockbox 变成应用**：从应用商店安装后，在资料库 → 应用里启动；安装不再让 Q2 开机进 Rockbox（要开机进请用系统设置 → 电源 → 默认启动）。
- **播放列表**：在 Cover Flow 的专辑封面上长按播放/暂停，可以「添加到播放列表」。
- **评分爱心**：1–4 颗心时爱心从底部按比例填充，替代角上的数字。
- **隐藏开关独立成页**：显示 → 外观 → 隐藏，把流媒体 / 文件夹 / 应用 / 游戏 / 应用商店 / Hi-Res 六个开关集中到一页。
- **充电上限与待机确认**：开启自动关机或待机时会先确认，说明充电上限在关机时不生效、待机可能导致无响应。
- **游戏**：「旋涡」改名「砖块」（Bricks），最高分保留。
- 其他：Cover Flow 翻面与返回的动画更顺；播放列表最多 500 首也能翻面；File Browser 的编辑标签重新看到正在播放的歌。

**中文版**

- 1.9.3 / 1.9.4 的新文案全部中文：锁屏布局与背景、采样率、快捷入口、年代的年代 / 年份、隐藏页、待机与关机确认、滑动解锁等。
- **恢复百度网盘**：流媒体页的「百度网盘」行回来了（1.9.0 合并时被上游版本覆盖，一直缺失）。
- 主菜单这一行维持「资料库」。

## 1.9.2（V192A）

上游 1.9.2（68 个提交），换到 1.9.2 版本线。刷机标记 `V192A` 与 `V191A` 不同，已刷 `V191A` 的机器可以直接 TF 卡刷，也会收到网络更新提示。

**修复**

- **正在播放的爱心**：在长按菜单里选「添加到收藏」或「从收藏中移除」后，爱心立刻填上或清空；原来要等下一首歌才更新，期间再点会撤销刚才的修改。
- **播放顺序**：改随机 / 重复 / 分组后，「上一曲」再「下一曲」回到你离开的那首歌；「加入队列」的歌不会被跳过；「查看队列」里删掉正在播放的最后一首、再加几首、然后选「下一首播放」不再越界（可能崩溃）；随机 + 重复单曲时下一轮正常开始。
- **VBR MP3 跳转**：带 CRC 保护的文件原来按平均码率估算，长混音里能差几分钟；现在会读它的跳转表。
- **EQ**：设成「左声道」或「右声道」的频段关掉再开仍是原声道（原来变回「双声道」）；从 SD 卡导入时不再列出 macOS 留下的 `._` 文件。
- **应用商店**：卸载应用不再删掉卡上被应用清单点名的文件；安装也不再往卡外建目录。
- **歌词**：只读标签里前 64 KB，避免一行几 MB 的歌词卡住或崩溃。
- **提示框**：第二个按钮不再都是「确定」——「关机？」是「关机」，「重启以应用？」是「重启」，「删除文件」是「删除」。
- 其他：Cover Flow 翻面卡显示专辑总时长（开启「检测歌曲时长」时）；Cover Flow 换封面更省 CPU；记忆播放只写位置、不再重写整个队列；几处提示框文字恢复了应有的间距；「快捷入口」的取值拼写统一。

**新增**

- **显示 → 外观新增「隐藏 Hi-Res」**：把资料库里的 Hi-Res 行拿掉。
- **语言**：装了中文语言包后，键盘从拼音页开始，一个键在拼音、小写、大写之间轮换（「中」/ abc / ABC）。
- 应用里搜索内容过长时会提示「搜索内容过长」，不再和名称 / 密码框共用一句「太长」。

**中文版**

- 1.9.2 的新文案全部中文：隐藏 Hi-Res、睡眠定时、EQ 导入全部与重置提示、关机 / 重启 / 删除按钮、USB 页「断开前请先弹出」等。
- **修好 V191A 的三处漏翻**：主菜单的「音乐」（1.9.1 的语言机制在没有语言包时显示了英文 `Library`）、设置页的「播放设置」与「系统设置」（同样显示成 `Playback` / `System`）。现在没有语言包时一律用资源自带的中文。

## 1.9.1（V191A）

上游 1.9.1（196 个提交），换到 1.9.1 版本线。刷机标记 `V191A` 与 `V190A` 不同，已刷 `V190A` 的机器可以直接 TF 卡刷，也会收到网络更新提示。

**新增**

- **卡主题（Card theme）**：把在 Q2 Theme Studio 里做好的 `theme.txt` 放进卡上的 `Q2Pod/` 文件夹，就能设定强调色与页面底色（简约 / 现代），以及正在播放与锁屏上元素的隐藏、移动、缩放、字号，首页各行的隐藏、改名、字号与轮播图片，还有所有主题下的电池样式。设置页会提示「卡主题已保存」，重启后生效；把文件从卡上拿掉，重启时会提示「卡主题已移除」，自己的设置原样回来。连续两次启动失败会自动关掉卡主题并提示。
- **语言应用**：从应用商店安装 Languages 后，系统设置里重新出现「语言」，共 34 种，含阿拉伯语等从右往左书写的语言。选中后整机重启即为该语言（Q2 Pod 自己的页面与设置也一起）；设置留在卡上，取出应用后下次启动回到英文。阿拉伯语、波斯语、乌尔都语的歌曲标题、表演者、专辑与歌词会按从右往左正确显示。
- **隐藏重复专辑 / 隐藏重复歌曲**：显示 → Cover Flow 里新增两个开关，默认关闭。「隐藏重复专辑」让同名同表演者的专辑只显示一张卡（比如不同文件夹里的 FLAC 与 MP3 副本），另一张卡的歌曲不再出现在 Cover Flow；「隐藏重复歌曲」让专辑里同碟号、同音轨号、同名的歌曲只列一次。两者都作用于 Cover Flow、表演者的封面与已评价专辑，专辑列表与卡上的文件不变。
- **记录失败封面**：显示 → Cover Flow，打开后进 Cover Flow，卡上的 `q2-crash.log` 会记下正在生成封面的是哪首歌，方便找出总卡在「正在准备封面」的那张专辑。默认关闭。
- **EQ 高级模式支持拖动**：在均衡器「高级」页的曲线上直接上下拖动某个频段即可调整增益，和「简单」页拖滑块一样；点按频段的光圈选中。改完选「应用更改」试听。
- **熄屏快进快退**：屏幕熄灭时，长按下一曲 / 上一曲可以快进或快退当前歌曲，松手就从那里继续播放；轻按仍然是切歌。
- **其他**：蓝牙页新增「接收音频」开关（关闭后 Q2 只发送音频，适合连 Echo 这类既能收也能发的音箱，改完需关闭再打开蓝牙）；卡带应用、卡带游戏与 Spotify **不再以管理员（root）身份运行**，应用出问题也读不到保存的 Wi-Fi 密码、改不了系统；待机时给存储卡最多 2 秒完成写入并卸载；曲库扫描保留每首歌的音轨号与碟号；记忆播放在关机或升级后回到原位置；按键音直接送蜂鸣器，不再先起两个小程序；熄屏待机时每秒只唤醒一次；「脉冲星」在安静的音乐下也会升起。

**中文版**

- 1.9.1 新增的界面文案全部中文：卡主题的全部提示、语言应用、隐藏重复专辑 / 歌曲、记录失败封面、接收音频、EQ 提示、Tidal 下载全部、月份表（1 月 – 12 月）与「上午 / 下午」、日期与时间页等。
- **体积**：上游这一版给字体做了瘦身——去掉设备端根本不读的字形名字表与 hinting 指令，字形数量一个没少（中文 515 个字形校验全过）。整个包比 `V190A` 小约 810 KB。

## 1.9.0（V190A）

上游 1.9.0（74 个提交），换到 1.9.0 版本线。刷机标记 `V190A` 与 `V189D` 不同，已刷 `V189D` 的机器可以直接 TF 卡刷，也会收到网络更新提示。

**新增**

- **Cover Flow 位置条可拖动**：在位置条上任意位置按住（即使它已经淡出），封面会跳到手指下的专辑并跟着手指走，跳得远时显示首字母。位置条停手后停留 1 秒（原来 0.8 秒）。在显示 → Cover Flow 打开。
- **评分列表长按随机播放**：在资料库 → 评价里的「评分最高」「喜爱」「全部已评价」「不喜欢」上长按播放/暂停，整张列表随机播放；长按列表里的歌曲仍然是打开歌曲菜单。
- **视频与阅读器变成卡带应用**：不再随固件提供，从资料库 → 应用商店 → 视频 / 书籍安装，再从资料库 → 应用 → 视频 / 书籍打开，用的还是卡上的 `Videos` 与 `Books` 文件夹。Wi-Fi 传输同时新增 WebM、MPEG、WMV、FLV、TS、M2TS、3GP、OGV 视频格式。
- **两个新可视化**：在可视化页点按切换，第 5 种「脉冲星」把音乐画成一层层向上堆叠的线，第 6 种「轮廓」在起伏的山形上画线，底鼓把主峰顶起来，低频托住峰，中频升起第二个峰。
- **卡带应用新能力**：整页全屏播放（像视频播放器那样），播放时接管声音并设置 Q2 的音量；能声明自己用不到网络（Smart Wi-Fi 不再为它常开 Wi-Fi）；能设置 EQ、读取正在播放的内容；能随 Wi-Fi 连接启动、断开停止；能在系统设置 → 网络里有自己的一行；页面能用开关行；能显示状态栏图标并随状态变化；游戏里能打开正在播放。
- **应用商店支持自定义源**：卡上 `.q2/custom-sources.list` 一行一个 `owner/repo 名称`，就能安装与更新列表之外的应用，显示在官方列表之后。
- **Wi-Fi 传输安全修复**：原来 Q2 把任何页面的请求都当成传输页自己的，局域网里另一个网站上的图片或表单可以清空卡上的文件夹。现在传输页只认 Q2 的数字地址，用脚本改卡需要带上 `Referer`。

**中文版**

- 1.9.0 新增的界面全部中文：脉冲星 / 轮廓、网络设置、EQ 提示、流媒体行、应用商店的新提示等。

## 1.8.9.4（V189D）

同一上游版本线上的第四个包（`1.8.9.3` → `1.8.9.4`）。刷机标记 `V189D` 与 `V189C` 不同，已刷 `V189C` 的机器可以直接 TF 卡刷，也会收到网络更新提示。

**修复**

- **Cover Flow 转轮失灵（V189C 引入，重要）**：V189C 为绕开模拟器的双精度限制，把转轮路径的整数转浮点换成内联汇编 `i2f()`，其中一处误把 `step < cap ? step : cap` 这个**浮点**三元式也包了进去——先截断成 int（约 0.14 变 0）再转回 0.0，转轮每格的位移恒为 0：抓取、转动、归位在同一帧内完成，圆盘怎么转封面都不动。本包去掉这层多余的 `i2f`，转轮恢复正常（模拟器验证：一格 -30 原始单位 → 偏移 -1，两格 → -6，与 1.8.8 时代一致）。
- 同时修正一处语义偏差：转轮减速曲线里的 `left * 100 / far_left` 恢复为**整数除法**（V189C 误改成了浮点除法），平滑函数收到与上游一致的整商。

## 中文版一直在做的（不是某一版新加的）

- **界面全中文**：自绘界面、卡内应用页的提示、游戏横幅、上游每版新增的文案，跟着版本一起翻。术语按 Apple《iPod classic 简体中文使用手册》。

- **状态栏「正在播放 / 播放暂停」**：经典主题放在页面名那一行，简约和现代跟在图标右侧，浅色深色都跟着变。
- **一键补全封面与歌词**：播放设置里一次扫全卡，先补专辑歌词，再补专辑封面，最后处理没有专辑标签的单曲。
- **酷狗封面优先**：在线封面先问酷狗，找不到再用其它来源。
