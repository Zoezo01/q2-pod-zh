# 更新日志（简体中文版）

本分支跟上游走：上游发一版，这里就把对应 tag 合进来，再把新出现的界面文字翻成中文，另外几个自己的功能一直在。下面从 **1.6.6（V166U，上一版公开发布）** 之后记起。

上游每一版的完整英文条目在 [docs/changelog.md](changelog.md)，这里只挑用户看得见的部分。

---

## 1.8.2（V182C）

同线上第三次发布，标记从 `V182B` 递进到 `V182C`：改过代码就得换标记，否则设备会把新包认成已装版本、拒绝升级。

**中文版**

- **顶栏元素统一垂直中线**（按实机截图逐项核对状态栏 widget 的真实几何）：
  - 简约／现代主题原来把右侧图标分组整体下移 1 行、又把左侧播放／暂停图标上提 1 行——这是早年为配合旧版 EQ 盒子做的补偿。EQ 改窄并改用与蓝牙图标同一行高之后，补偿只剩副作用：播放图标、播放状态文案、中间时钟都比右侧 EQ／Wi-Fi／电池高出一行。两处偏移都撤掉，左右分组共用 y=0 的整行高度。
  - 电池设为「只显示百分比」时，百分比是代码自绘的；它所在的槽位原来取整个顶栏高度（经典主题 26 px），而图标分组只有 22 px，于是「44%」比 Wi-Fi 和播放／暂停图标低约两行。槽位改跟随所在分组的行高，经典主题三者归到同一中线。
  - 自绘百分比补上 1 行光学补偿（数字的墨迹比居中图标略高）；经典主题用自己的字体和短行，不加这一行。
- 测试断言跟随新几何：电池槽位高度、百分比绘制矩形、经典主题槽位高度。

## 1.8.2（V182B）

同线上第二次发布。设备升级只认「标记不同」，所以本版标记从 `V182A` 递进到 `V182B`：已经刷过 `V182A` 的机器直接 TF 卡刷本包即可，不会被当成同一个版本拒绝。

**中文版**

- 按实机截图修了一批界面问题：
  - **歌单页补齐汉化**：经典主题里剩下的「新建播放列表…」「全选」「选择播放列表…」「导出」「删除」等动作行、歌单行的「N Songs」（改成**「N 首」**）和删除确认框的动作词（改成**「删除」**）。
  - **状态栏右侧图标归到同一行**：经典主题原来给蓝牙 +1 行、Wi-Fi −1 行，和电池百分比错成上／中／下三条；「状态栏外观」选「经典」时，简约／现代主题也跟着错位。EQ 标记的宽度从 28 px 收到 22 px 并居中，不再和 Wi-Fi 之间空出一倍多余间距。
  - **经典主题三级页面**（背光亮度、夜览等）深色顶栏的菜单名从屏幕最左边移到圆角安全区并左对齐，不再被玻璃圆角遮住；播放／暂停图标改用和浅色顶栏同尺寸的白色图形（12×14 墨迹），与电池共用中线。
  - **简约／现代主题顶栏**：菜单名移到**左侧**（播放／暂停图标仍固定最左），并和「正在播放／播放暂停」文案**择一显示**——有菜单名时显示菜单名，没有时才显示播放状态。菜单名不再加粗，长名字（如 `Cover Flow`）限制在左侧标签内，不会再压到 EQ、时钟或电池上。
- 上游测试的中文映射表生成器改按上游 1.x 版本线选默认基线：仓库里另有 `9.2`–`9.8` 这批旧编号 tag，纯按数字排序会误选 9.8、把 595 组映射刷成 72 组。
- 文档补齐版本标记的递进规则：改过代码就要把 `TAG` 末位字母往后移，否则同标记的设备会拒绝升级。

## 1.8.2（V182A）

**中文版**

- 上游 **1.8.1** 与 **1.8.2** 一并合入（170 个提交），新出现的界面文字全部译成中文：AirPlay 的入口与安装提示、电池历史页（含行上的时间与日期、导出的日志）、USB DAC 充电、Cover Flow 的位置条与歌曲时长、卡应用的「处理中…」「取消」「搜索词太长」、收藏失败的几条提示。
- **「大曲库模式」改名「快速导航」**：上游把 Large Library Mode 换了这个名字，功能没变，开关还是原来那个。
- 长按菜单里的「编辑播放列表…」跟着上游改成**「选择播放列表…」**（它标的是要导入、导出或删除哪几个歌单；改歌单里的歌用它的「更多 → 编辑播放列表」）。播放列表页的选择模式标题同样改成「选择播放列表」。
- 外观页的**「快捷入口」**多一个选择**「无」**，选它主菜单就没有那一行。
- 快捷设置里长按播放键的提示改用主题自己的浮层（上游在 1.8.2 换掉了那条黑色窄条），文字仍是**「滚轮：音量 / 滚轮：亮度」**。
- 经典主题的**「更新曲库」对话框**，标题栏补上中文**「更新曲库」**：这里原来硬编码的是英文 `Update Library`，是仅剩的一处没翻的标题。
- 游戏里的弹出框（开始新游戏、已暂停、继续 / 退出、新纪录、游戏结束）改用上游的主题化弹窗，各主题有自己的底色和选中条，文字保持中文。

**上游**（详见 [docs/changelog.md](changelog.md)）

- **AirPlay**（1.8.1）：在 系统设置 → 应用商店 装 AirPlay，然后在正在播放的 **⋯** 页选 **AirPlay** 和音箱。Q2 静音、音箱放同一首歌（约晚一秒），暂停、切歌、拖进度都跟着走，滚轮调音箱音量（和耳机音量分开记），歌词也跟过去。只支持本地音乐和 Tidal，DSD 仍在 Q2 上放。
- **电池历史**（1.8.1）：系统设置 → 电源 → 电池历史，画出自上次拔充电线以来电量怎么掉的，每掉 1% 一行带时间，待机、关机都记。**导出日志**把它写到卡根目录的 `battery-log.txt`。
- **Cover Flow**：新增可选的**位置条**（显示 → Cover Flow 里打开），转轮或触摸浏览时跟着走、停下后淡出；专辑曲目后面带回歌曲时长（可开**检测歌曲时长**，在 显示 → Cover Flow，默认关）；打开时定位到正在播放（或暂停）的那首歌的专辑；封面随轮子列队、快转时弯成拱形，三套主题一致。
- **USB DAC 充电**（1.8.2）：系统设置 → 电源 → USB DAC 充电，决定 USB 模式为「音频与 DAC」时 Q2 要不要充电，默认开。以前这个开关只在电脑或手机接上后才出现，DAC 模式下的 Q2 可能看着像没电了。
- 状态栏的电池**只在真充电时变绿**（1.8.2）。插着线但没充（DAC 模式关了充电、或充电上限到了 80%）以前也是绿的，现在保持白色，低于 15% 仍是红色。
- 开**无耳机不播放**时，开机也会把队列恢复成暂停状态（1.8.2），不再什么都不恢复。
- **滚轮灵敏度**最低到 **10%**（1.8.1），20% 时一格要转三分之一圈，10% 要转大半圈。
- 搜索页键盘弹起时，单击中心键不再直接灭屏（要双击），看着不再像卡死。
- **Wi-Fi 传输**的文件管理器修了注入漏洞：文件名或文件夹名里带 `$(…)` 或反引号，以前会在 Q2 上当成命令执行，特制的请求还能读写卡外或隐藏的文件。现在名字按原样保留，操作也不出卡。
- 卡应用：某一行在等应用回话时显示**「处理中…」**，这期间再按不再重复发送；页面可以只给「重试」和「取消」；正在播放的爱心能给应用里的歌加收藏。
- 其它：经典主题下电池显示多了**「百分比」**单显；Now Playing 的队列位置和标题对齐；卡应用暂停时的音量、封面、歌词跟着走；书本内存检查放宽（18 小时的书也能放）。

## 1.8.0（V180A）

**中文版**

- **流媒体页找回百度网盘**。官方固件本来就有这一行（设备上出码，手机百度 App 扫码登录），上游从很早的版本起就把它从流媒体页删掉了，1.8.0 也不例外。现在按原样放回去，登录、浏览、下载都走官方实现。

## 1.6.9 / 1.6.8 / 1.6.7

这三个版本基本都在把经典主题做成真正 iPod classic 的样子，条目非常多，这里只挑明显的：

- **锁定屏**改成信息屏：日期条、带表盘的时钟托盘（或只有大时钟）、歌曲托盘，压着壁纸。
- **快捷设置**独立成页：圆角按钮、新的亮度条带旋钮；经典主题下音量是玻璃面板，条夹在两个喇叭中间。
- **搜索**：经典主题有 T9 键盘、自己的页签和两行结果；历史搜索、X 的配色、搜索框背后的深色条都齐了。

- 新增**「设置时间」和「设置日期」**页：旁边有时钟表盘或日历块，24 小时制和 12 小时制都有。
- **正在播放**：封面放大斜放、带倒影，进度条是 iPod 那种粗的，两侧时间更大，拖动时条上有菱形标记；信息页变成左名右值的列表。

- Spotify、网络电台、第三方卡应用在经典主题下也按本地曲目的样子显示。
